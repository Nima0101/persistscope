# Code of conduct

This project welcomes contributors of all backgrounds and experience levels. Treat people respectfully, give specific technical feedback, and make room for questions and disagreement.

Harassment, discriminatory language, threats, unwanted sexual attention, deliberate disruption, and disclosure of another person's private information are unacceptable. Critique code and reasoning rather than personal characteristics.

Maintainers may edit or remove content, close discussions, or restrict participation to protect contributors. Responses should be proportionate to the conduct and may include a warning, temporary restriction, or permanent ban.

Report concerns privately through the maintainer contact options on [Nima0101's GitHub profile](https://github.com/Nima0101). Do not publish sensitive incident details in an issue. Reports will be handled with discretion; confidentiality cannot be guaranteed beyond the tools used to communicate.

This policy applies to project issues, pull requests, discussions, and other spaces where someone represents the project.
